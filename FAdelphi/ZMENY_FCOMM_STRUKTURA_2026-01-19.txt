DUVOD
-----
FComm utility by mely byt zcela nezavisle na projektu FA, podobne jako EPMF
slozka. Umoznuje to pouziti v jakemkoliv Delphi projektu a lepsi separaci
zodpovednosti.

PROVEDENO
---------

1. VYTVORENA SLOZKA FComm/
   - Nova samostatna slozka pro FComm infrastrukturu
   - Stejny princip jako EPMF/ slozka

2. PRESUNUTY SOUBORY:
   FAdelphi/FCommHttpClient.pas   → FAdelphi/FComm/FCommHttpClient.pas
   FAdelphi/FCommLifecycle.pas    → FAdelphi/FComm/FCommLifecycle.pas
   FAdelphi/FCommJsonHelper.pas   → FAdelphi/FComm/FCommJsonHelper.pas

3. SMAZAN FCommPlatform.pas
   - Zbytecny overhead po odstraneni Windows 7 podpory
   - Funkce GetFCommExePath() presunuta jako private do FCommLifecycle.pas

4. UPRAVENY USES:
   
   EPMF\mfcr_certificate_api.pas:
   - Pridano do uses: FCommHttpClient, FCommJsonHelper, FCommLifecycle
   - Nutne pridat FComm\ do Search Path v Delphi IDE
   
   FComm\FCommLifecycle.pas:
   - ODSTRANENO: uses FCommPlatform
   - PRIDANO: private function GetFCommExePath: string;

5. NOVA DOKUMENTACE:
   + FComm/README_FCOMM.md - Kompletni dokumentace FComm infrastruktury

POUZITI V JINYCH PROJEKTECH
----------------------------

Pro pouziti FComm/ v jinem Delphi projektu:

1. Zkopirovat slozku FComm/ do projektu
2. Pridat do Search Path:
   Project → Options → Directories/Conditionals → Search path
   Pridat: FComm\

3. Uses:
   uses
     FCommHttpClient,
     FCommJsonHelper,
     FCommLifecycle;

4. Pouzit:
   var Lifecycle: TFCommLifecycle;
   begin
     Lifecycle := TFCommLifecycle.Create;
     try
       Lifecycle.Start(''); // Najde fcomm.exe automaticky
       // ... prace s API
     finally
       Lifecycle.Free;
     end;
   end;

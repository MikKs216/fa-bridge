Format

Vrací formátovaný řetězec sestavený z formátu řetězce a řady argumentů.

 

Syntaxe:

function Format(const Format: string; const Args: array of const): string;

 

Parametry:

Format - řetězec (obsahující formátovací znaky), který budeme formátovat

Args - pole argumentů, které jsou aplikovány na formátovací znaky

 

Result:

Vrací formátovaný řetězec sestavený z formátu řetězce a řady argumentů.

 

Unit

Delphi | SysUtils

 

Příklad:

var

 text : string;

begin

 // pouze jedna položka

 ShowMessage(Format('%s', ['Hello']));

 

 // Mix textu a datových položek

 ShowMessage(Format('String = %s', ['Hello']));

 ShowMessage('');

 

 // Příklady každého z datových typů

 ShowMessage(Format('Decimal          = %d', [-123]));

 ShowMessage(Format('Exponent         = %e', [12345.678]));

 ShowMessage(Format('Fixed            = %f', [12345.678]));

 ShowMessage(Format('General          = %g', [12345.678]));

 ShowMessage(Format('Number           = %n', [12345.678]));

 ShowMessage(Format('Money            = %m', [12345.678]));

 ShowMessage(Format('Pointer          = %p', [addr(text)]));

 ShowMessage(Format('String           = %s', ['Hello']));

 ShowMessage(Format('Unsigned decimal = %u', [123]));

 ShowMessage(Format('Hexadecimal      = %x', [140]));

end;

 

Výsledek:

  Decimal          = -123

  Exponent         = 1.23456780000000E+004

  Fixed            = 12345.68

  Money            = ?12,345.68

  String           = Hello

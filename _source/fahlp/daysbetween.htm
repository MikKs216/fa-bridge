DaysBetween

Vrací počet celých dní mezi dvěma datumovými údaji.

 

Syntaxe:

function DaysBetween(const ANow, AThen: TDateTime): Integer;

 

Parametry:

ANow - počáteční datum

AThen - konečné datum

 

Result:

Vrací počet celých dní mezi dvěma datumovými údaji.

Počítá pouze celé dny, tzn. výsledkem rozdílu mezi 01.01.2016 23:59 a 02.01.2016 23:58 je 0, protože do celého dne chybí 1 minuta.

 

Unit

Delphi | DateUtils

 

Příklad:

var

 fromdate, toDate : TDateTime;

 

begin

 // Nastavení našich dat

 fromDate := EncodeDateTime(2000, 02, 26, 10, 0, 0, 0);

 toDate   := EncodeDateTime(2000, 02, 29,  9, 0, 0, 0);

 

 // Zobrazit tyto data a dny mezi nimi

 ShowMessage('From date = '+DateTimeToStr(fromDate));

 ShowMessage('To   date = '+DateTimeToStr(toDate));

 ShowMessage('Whole days difference = '+

             IntToStr(DaysBetween(toDate, fromDate))+' days');

end;

 

Výsledek:

 From date = 26.02.2016 10:00:00

  To   date = 29.02.2016 09:00:00

  Whole days difference = 2 days  // rozdíl mezi 2 daty

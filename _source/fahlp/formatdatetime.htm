FormatDateTime

Naformátuje datum TDateTime do požadovaného řetězce.

 

Syntaxe:

function FormatDateTime(const Format: string; DateTime: TDateTime): string;

 

Parametry:

Format - formát, do kterého chceme datum převést, viz. níže

DateTime - zadané datum

 

Result:

Naformátuje datum TDateTime do požadovaného řetězce.

Pokud je parametr Format prázdný, použije se formát 'c'.

 

Unit

Delphi | SysUtils

 

Příklad:

Pro znakové formátování řetězce mohou být použity v řetězci:

y        = Rok poslední 2 číslice

yy        = Rok poslední 2 číslice

yyyy        = Rok poslední 4 číslice

m        = Měsíc bez úvodní 0

mm        = Měsíc poslední 2 číslice

mmm        = Měsíc pomocí ShortDayNames (Jan)

mmmm = Měsíc pomocí LongDayNames (January)

d        = Den bez úvodní 0

dd        = Den jako 2 číslice

ddd        = Den pomocí ShortDayNames (Sun)

dddd        = Den pomocí LongDayNames (neděle)

ddddd        = Den v ShortDateFormat

dddddd        = Den v LongDateFormat

       

c        = Použití ShortDateFormat + LongTimeFormat

h        = Hodiny bez úvodní 0

hh        = Počet hodin jako 2 číslice

n        = Minuty bez úvodní 0

nn        = Minuty jako 2 číslice

s        = Sekundy bez úvodní 0

ss        = Sekundy jako 2 číslice

z        = milisekundy bez úvodní 0

zzz        = milisekundy jako 3 číslice

t        = Použít ShortTimeFormat

tt        = Použít LongTimeFormat

       

am/pm        = Použití pro hodiny: 12 hodin + AM / PM

a/p        = Použití pro hodiny: 12 hodin + A / P

/        = Použití pro oddělení data

:        = Použití pro oddělení hodin

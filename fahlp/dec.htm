Dec

Sníží číslo X o hodnotu 1, resp. o hodnotu uvedenou v proměnné N.

 

Syntaxe:

procedure Dec(var X [ ; N: Longint ]);

 

Parametry:

X - číslo, které chceme snižovat

N - hodnota, o kterou budeme číslo snižovat. Pokud není uvedeno, sníží se číslo o 1;

 

Unit

Delphi | SysUtils

 

Příklad:

var

 Number    : Integer;

begin

 Number := 23;

 

 ShowMessage('Number : '+IntToStr(Number));

 

 Dec(Number);

 ShowMessage('Number-1 : '+IntToStr(Number));

 

 Dec(Number, 5);

 ShowMessage('Number-5 : '+IntToStr(Number));

end;

 

Výsledek:

  Number : 23

  Number-1 : 22

  Number-5 : 17

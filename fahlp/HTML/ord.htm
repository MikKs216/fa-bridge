Ord

Vrací pořadovou hodnotu výrazu ordinálního typu.

 

Syntaxe:

function Ord(X);

 

Result:

Výsledkem je pořadová hodnota X.

 

Unit

Delphi | System

 

Příklad:

var

 A   : AnsiChar;

 C   : Char;

 W   : WideChar;

 E   : Boolean;

 I   : Integer;

 I64 : Int64;

 

begin

 // nastavení hodnoty

 A   := 'A';

 C   := 'C';

 W   := 'W';

 E   := True;

 I   := 22;

 I64 := 64;

 

 // zobrazení hodnot

 ShowMessage('A = '+IntToStr(Ord(A)));

 ShowMessage('C = '+IntToStr(Ord(C)));

 ShowMessage('W = '+IntToStr(Ord(W)));

 ShowMessage('E = '+IntToStr(Ord(E)));

 ShowMessage('I = '+IntToStr(Ord(I)));

 ShowMessage('I64 = '+IntToStr(Ord(I64)));

end;

 

Výsledek:

  A = 65

  C = 67

  W = 87

  E = 1

  I = 22

  I64 = 64

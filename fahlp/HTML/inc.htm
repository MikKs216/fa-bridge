Inc

Zvýší číslo X o hodnotu 1, resp. o hodnotu uvedenou v proměnné N.

 

Syntaxe:

procedure Inc(var X [ ; N: Longint ]);

 

Parametry:

X - číslo, které chceme zvyšovat

N - hodnota, o kterou budeme číslo zvyšovat. Pokud není uvedeno, zvýší se číslo o 1;

 

Unit

Delphi | SysUtils

 

Příklad:

var

 Number    : Integer;

begin

 Number := 23;

 

 ShowMessage('Number : '+IntToStr(Number));

 

 Inc(Number);

 ShowMessage('Number+1 : '+IntToStr(Number));

 

 Inc(Number, 5);

 ShowMessage('Number+5 : '+IntToStr(Number));

end;

 

Výsledek:

  Number : 23

  Number+1 : 24

  Number+5 : 29
